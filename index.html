⚙

Encryption Formula

E(x) = ((x + k1) × k2 + k3) mod 32

Each letter is shifted by k1, scaled by k2 (must be odd), then shifted again by k3. The result is encoded as a 6-bit token in the bitstream.

🔓

Decryption Formula

D(y) = ((y - k3) × k2⁻¹ - k1) mod 32

Reverses encryption using the modular inverse of k2 (mod 32). Spaces are encoded as the special token 100000 in the bitstream.

📡

Bitstream Encoding

Letter → 0[5-bits] | Space → 100000

Every character becomes exactly 6 bits. Letters are prefixed with 0; spaces use the reserved code 100000 which is unambiguous.
